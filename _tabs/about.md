# About

I’m **Michael Walsh**, a Principal Software Engineer specialising in **.NET and Azure**.

I design, build, and operate **cloud-native distributed systems** on Azure — with a focus on **scalability, reliability, and observability**.

Recent work includes:

- Implementing distributed tracing with **OpenTelemetry → Application Insights**.  
- Building serverless solutions using **Azure Functions**, **Service Bus**, and **Azure Pipelines**.

I enjoy sharing practical demos and writing about cloud engineering topics on [my blog](https://www.michaelwalsh.co.uk) and [Medium](https://medium.com/@mca.walsh).

⚙️ Always learning, building, and exploring what’s next with .NET and Azure.
